# Lego AI - project folder

Turn LEGO Technic instruction booklets into labeled training data (part, position, connections, function, where each part is later), to eventually design custom Technic sets. Owner: Dennis.

## What's in here
| File | What it is |
| --- | --- |
| 00_README.md | This file |
| 01_INSTRUCTIONS.md | The instructions you give the labeling AI (paste into a Claude Project) |
| 02_FRAMEWORK.md | The labeling rules: pipeline, fields, the four-part answer, verbs, checks |
| 02_PLAN.md | Status, next steps, 5-week plan, how to train |
| 03_training_data/8047.jsonl | Finished training examples, one per line |
| 03_training_data/8047.tbl | Same steps in the build language |
| 03_training_data/8047_preview.md | Every labeled step, easy to read, with pictures (generated) |
| 03_training_data/8047_part_matches.csv | Every named part matched to a catalog part number (generated by make_preview.py) |
| 04_reference/8047_parts_list.csv | Official parts list for set 8047 (252 pieces, 67 types) |
| 05_booklets/steps/ | One picture per step |
| 05_booklets/8047_steps.csv | Booklet map: main steps, side builds, pages |
| make_preview.py | Rebuilds the preview and part matches from the JSONL |
| check_steps.py | Checks every step: parts on the list, counts, verbs, names, why |

Live docs (editable): Plan https://claude.ai/artifact/3UqS1JRTkBuiq9jE5KFjfm and Framework https://claude.ai/artifact/9agc7uxAr16TjJK2EYirj4

## How to use it as a Claude Project
1. Create a Project, paste 01_INSTRUCTIONS.md into its instructions.
2. Upload 02_FRAMEWORK.md, the training data, the parts list and the booklet PDF as project files.
3. In a chat: "Label step 15 (page 7)." Check the answer, fix it, add the fixed line to the JSONL.
